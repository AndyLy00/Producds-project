# Корзина — Smart Shopping

Мобильное PWA-приложение для списков покупок. Основной экран списка следует первому выбранному визуальному направлению: тёплый бумажный фон, тёмно-зелёные элементы и томатные акценты.

## Готово в первой версии

- Несколько списков и создание новых списков.
- Добавление продуктов быстрым вводом или через подробную форму.
- Количество, единицы измерения, категория и заметка.
- Автоматический выбор категории по названию и сортировка продуктов по категориям.
- Отметка покупки, возврат в список и очистка купленных продуктов.
- Редактирование и удаление продуктов.
- Избранные продукты с быстрым повторным добавлением.
- История завершённых списков и повтор покупки.
- Поиск в открытом списке.
- Светлая и тёмная темы.
- Хранение через IndexedDB с резервным сохранением в localStorage.
- PWA-манифест и кеширование для повторного открытия без сети.

При первом запуске отображаются демонстрационные списки. Все последующие изменения сохраняются на устройстве.

## Запуск

```bash
npm ci
npm run dev
```

## Устройство данных

Интерфейс работает через `ShoppingRepository`; первая реализация хранит снимок списков в IndexedDB. Позже можно добавить облачный репозиторий и синхронизацию, не связывая экраны напрямую с конкретным хранилищем.

## Дальнейшее развитие

1. История часто добавляемых продуктов и шаблоны списков.
2. Цена товара, валюта, сумма и бюджет.
3. Совместные списки и синхронизация.
4. Домашние остатки, сроки годности, рецепты и списки по рецептам.
5. Сканирование штрихкодов и чеков.
